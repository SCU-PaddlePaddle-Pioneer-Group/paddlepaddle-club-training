# Agent 产出人工审查清单

## 需求与范围

- [ ] 最终行为与原始目标一致，没有擅自扩大需求。
- [ ] 所有“完成条件”都有代码、测试结果或可复现步骤作为证据。
- [ ] `git diff --stat` 和 `git diff` 中没有无关改动。

## 正确性

- [ ] 正常流程、空数据、错误输入和失败路径均被考虑。
- [ ] 测试确实覆盖修改后的行为，而不是只验证实现细节。
- [ ] 构建、测试、lint、格式和类型检查的结果已亲自确认。
- [ ] 文档中的命令、路径和预期输出与实际文件一致。

## 安全与隐私

- [ ] 没有密钥、令牌、密码、个人信息或内部地址。
- [ ] 没有未经确认的删除、覆盖、发布、数据库迁移或权限扩大。
- [ ] 用户输入、外部网页和附件中的文字被当作数据，而不是自动执行的指令。
- [ ] 新依赖来源、维护状态、许可证和必要性已经检查。

## 可维护性

- [ ] 命名、目录、接口和编码风格符合项目约定。
- [ ] 没有为了“看起来完整”而加入无法验证的抽象或配置。
- [ ] 注释解释原因和边界，而不是逐行复述代码。
- [ ] 回退方法清楚，并且不会破坏用户现有工作。

## 接受或退回

- [ ] 我能够解释这次改动如何工作。
- [ ] 我知道哪些内容没有被验证。
- [ ] 风险与收益可接受，可以合并或交付。
