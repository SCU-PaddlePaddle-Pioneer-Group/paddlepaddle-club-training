# AI 类培训资料

面向飞桨社团成员的人工智能基础、模型应用与 AI 工程学习。

## 学习路径

1. Python、线性代数、概率统计与优化基础
2. 机器学习基本概念与经典算法
3. 深度学习与 PaddlePaddle / PyTorch
4. 计算机视觉、自然语言处理与多模态
5. 生成式 AI 与大语言模型
6. Prompt、RAG、Agent 与 LLM 应用开发
7. 模型评测、部署、监控与安全

## 主题目录

将各主题资料放在本目录下，例如：

```text
ai/
├── foundations/
├── machine-learning/
├── deep-learning/
├── computer-vision/
├── natural-language-processing/
├── generative-ai/
├── llm-applications/
└── mlops-and-safety/
```

## 推荐主题模板

每个主题的 `README.md` 至少包含：学习目标、先修知识、关键概念、代码实验、数据或模型来源、评测方式和延伸阅读。

涉及模型、数据集或第三方 API 时，请记录版本、使用限制和许可证信息。
