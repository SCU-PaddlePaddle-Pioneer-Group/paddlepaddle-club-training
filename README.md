# 飞桨社团技术培训资料

面向四川大学飞桨领航团成员的技术培训与自学资料库，按主题分为开发与 AI 两大类，服务于社团内部分享、课程学习和项目实践。

## 目录

### 开发

- [开发培训资料](./development/README.md)
- 编程基础、工程实践、Web 开发、数据库、测试、DevOps 与软件架构

### AI

- [AI 培训资料](./ai/README.md)
- 数学基础、机器学习、深度学习、生成式 AI、LLM 应用与 AI 工程

## 资料组织约定

每个培训主题建议单独建立目录，并包含：

```text
topic-name/
├── README.md       # 学习目标、先修知识与课程大纲
├── notes/          # 讲义与知识点
├── examples/       # 示例代码或练习
└── exercises/      # 作业、实践题与参考答案
```

## 社团协作

1. 在对应分类下创建主题目录。
2. 为主题补充清晰的学习目标、资料来源和实践任务。
3. 示例代码应注明运行环境；外部资料请保留原始链接与许可证信息。
4. 提交 Pull Request，并在描述中说明适用人群、培训时长和分享人。

欢迎社团成员补充讲义、实验代码、练习题和项目复盘材料。
