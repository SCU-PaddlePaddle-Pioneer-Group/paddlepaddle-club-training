输入网址后，浏览器先通过 DNS 找到服务器地址，再向服务器发送 HTTP 请求。服务器返回 HTML；浏览器解析 HTML 后，通常还会继续请求 CSS、JavaScript 和图片。

## 用开发者工具观察

打开浏览器开发者工具的 Network 面板并刷新页面，可以看到每个资源的 URL、状态码、类型、大小和耗时。

常见状态码包括：

- `200`：请求成功；
- `301` 或 `308`：资源被永久重定向；
- `404`：资源不存在；
- `500`：服务器内部错误。
